# 直方图标注

打开离线页面 `index.html`，在「图表大类」选择「Histogram / 直方图」，再选择子类和方向。单系列、重叠和堆叠直方图均可使用等宽或不等宽分箱。

## 录入与测量

1. 录入原图的图表标题、轴标题和单位。按可靠来源每箱填写一行 `bin_start`、`bin_end` 和 `value`。多系列先填写系列名称，再为每行选择对应系列。
2. 若需像素测量，用「坐标轴校准」在对应数值轴指定两个像素位置并填写真实刻度值。纵向使用 X 轴测边界、Y 轴测统计值，横向交换两轴。纵向和横向均可独立校准任一轴。
3. 可逐行手填，也可输入分箱数量（Bin Count）开始连续录入。单系列和重叠图先取第一箱的起始、结束和统计值端点。从第二箱开始，起始边界默认承接上一箱的结束边界，直接取结束边界和统计值。重叠图先在「当前系列」选定系列，再选择「开始连续录入」或「逐条标定当前系列」。完成后可手动切换到另一个系列。
4. 用「上一步」回到上一测量项，或选择测量项后使用「重测当前项」。继承的起始边界可以直接改写或重新取点。手填保留原精度，清空单元格后可重新取点。重新校准会更新仍有像素依据的字段。刻度失效时，可重新校准或改用手填。

### 堆叠直方图

1. 在「堆叠共享分箱边界」添加、删除分箱或修改起始和结束边界。选择分箱编号，点「测量选中分箱」，再选起始或结束边界取点。也可填写分箱数量并点「连续标注分箱」。首箱取两个边界，后续默认继承上一箱的结束边界。
2. 在「数据记录」为每条堆叠段记录选择所属分箱和系列。选择记录后，可单独取段底和段顶（横向为左侧和右侧），也可手填统计值。修改共享边界会更新引用它的记录。删除分箱后，仍可为原记录重新选择分箱，统计值和测量证据会保留。
3. 分箱就绪后，可另行启动「连续标注系列」。先设置系列数量、名称和全局顺序，纵向按底部到顶部，横向按左侧到右侧。取点时先将像素转成统计值轴上的数据坐标，再以终点减起点，保留两位小数。点击「跳过缺失系列」继续下一箱。
4. 工程备份保留当前步骤、共享边界、跳过状态和未完成段的取点。恢复后可继续录入。完成后核对原图和数值来源，再使用质量检查、预览和 GT 导出。

## GT 结构

| 子类 | 数据行 | 统计值轴与系列 |
| --- | --- | --- |
| 单系列 | `bin_start`、`bin_end`、`value` | `value` |
| 重叠 | 另含 `series` | 统计值轴设 `stack: null` |
| 堆叠 | 另含 `series` 和 `stack_order` | 统计值轴设 `stack: "zero"`，`order` 映射 `stack_order` |

三种子类均使用 `mark: {"type": "bar"}` 和预分箱边界。纵向分箱使用 `x / x2`，横向使用 `y / y2`，起始边界带 `bin: "binned"`。多系列用 `color` 映射 `series`，类型为 `nominal`，`sort: null`。统计值沿用原始含义和数值，精简 GT 保留轴标题和单位，像素证据和校准参数随工程备份保存。

堆叠 GT 允许稀疏记录，各箱只包含实际存在的系列，各系列保留全局顺序。质量检查会标出无效边界、重复分箱和系列组合、不一致的堆叠边界或顺序，以及负的堆叠段统计值。分组直方图超出当前版本范围。语义预览采用参考 GT 的默认比例尺和轴方向。

运行 `npm run build` 可重建离线页面，`npm test` 包含直方图浏览器测试。
