# 柱线复合图标注

图表大类选择「柱线复合图」。本次支持共享类别 X 轴的分组纵向柱＋折线，以及柱用左 Y、折线用右 Y 的双轴形式。沿用同一工作区、图像队列、类别/系列对象、校准、取点、表格、撤销、精度辅助、核对和导出；没有新增独立标注页面或运行时依赖。

## 操作

1. 上传原图，在图表大类中选择柱线复合图。类别按图片从左到右填写，重复文本位置仍是不同类别对象。
2. 在原有系列列表中为每个系列选择「柱」或「线」，至少各一组。可以新增、改名和调整顺序；已存在记录的系列不能直接改角色，避免误差/路径字段和像素归属被静默改变。新增系列默认是柱，录入前可改成线。
3. 共用 Y 轴时只校准左 Y；双轴时勾选双 Y 轴，分别校准左 Y（柱）和右 Y（折线）。轴类型可选线性或对数，原图像素和真实刻度各自保存。类别 X 不需要数值校准。
4. 选择当前类别、系列，通过原有取点工具测量。柱测数值端点，折线沿真实路径测顶点；同一像素可以在不同系列重复记录。各系列自动使用对应 Y 轴换算。手动模式允许路径回退与重复类别的连接，导出只在实际 X 回退时保存 `path_order`。
5. 柱含误差棒时勾选相应选项，复用「逐柱」或「分轮」流程。仅柱请求数值、上界、下界；折线只请求数值，表格中折线误差列和柱路径列不可填写。
6. 现有拖动、键盘微调、类别定位锁定、投影线、独立放大镜继续可用。分组柱的定位按类别＋柱系列保存；折线共享类别中心定位。选中记录后微调使用该记录所属轴，而不是当前取点系列的轴。
7. 修改轴校准只重新换算对应数值轴上有像素依据的记录，自动数值应用 Precision V2。手动录入保留数值精度并解除对应记录的像素依据；其他记录证据不改变。可撤销、重做或保存 v2 工程继续工作。
8. 检查原图、表格和语义重绘后，沿用原有人工核对勾选。单图 GT 和批量 ZIP 均使用同一转换函数；未核对不会导出。

## 精简 GT

图内统一使用 `category/value`，行顺序为柱在前、折线在后；角色内沿用分组柱/折线的顺序规则。行结构：

```json
{"category":"A","value":12,"lower":10,"upper":14,"series_role":"bar","series":"Volume"}
{"category":"A","value":0.25,"series_role":"line","series":"Rate"}
```

按需在 `category` 后插入 `category_id`，在 `value` 后保留柱 `lower/upper` 或折线 `path_order`，再写 `series_role`、`series`，重复系列身份 `series_id` 始终最后。重复类别/系列使用全图统一 C/S 身份，跨角色也不合并同名对象。没有可读图例时按全图首次可见顺序使用匿名 Series N，并隐藏图例。

顶层 `encoding` 共用 X/Y/color；角色层用精确的 `series_role` filter。多柱系列仅在柱和误差层设置 `xOffset`，offset domain 仅含柱系列，避免折线占用柱槽。误差层统一使用原生 `errorbar`，兼容导入生成器旧 `rule`。

双轴用 `resolve.scale.y = "independent"`，柱和误差层放入同一嵌套柱组，折线为独立兄弟图层；右轴标题、单位和线性/对数设置独立保留，不把左右单位混为一组。反向轴保留 `scale.reverse`。原图布局、颜色、像素和校准数据保存在工程，不进入训练 GT。

GT 导入沿用原「导入 GT」控件，识别 `series_role` 并恢复系列角色、重复身份及轴关系。导入不推断原图像素证据；之后仍需重新核对。未知科学字段、额外变换、图层与角色不符、同一系列混用角色、未知分组/尺度不进行有损猜测。

## 验证和边界

```bash
npm run test:composite
npm test
```

语义测试使用原应用模型与实际捆绑 Vega-Lite/Vega。覆盖共享/双轴、多个柱组、绝对误差上下界、C/S 重名、匿名系列、对数轴、折线路径和非法输入。实际 Vega-Lite-DG 样例覆盖共享/双轴×有/无误差棒，保留精确科学数值并验证导出后重新导入。浏览器测试通过现有控件执行校准、重合点取样、轴重算、表格修改、键盘微调、撤销、工程恢复、人工核对与 GT 下载。

当前复合类型只覆盖纵向柱＋折线，共享离散类别轴；横向复合、连续 X、任意多图层/多面板组合和更多独立值轴没有混入本次类型。上游面积图、饼图角度测量及普通柱线散点行为由完整回归继续覆盖。
