# Pie / Box Plot 本地开发与验证

实现已集成到 main 的 `studio.js` 与 `studio.template.html`，通过 `node build.mjs` 同步离线 `index.html`。没有新增运行时依赖或独立标注页面。统计图复用上游稳定类别对象、独立放大镜、校准、编辑、撤销、项目管理与批量 ZIP。工程沿用上游版本 2，并兼容版本 1 历史工程。

统计图 Compact GT 与同级 `Vega-Lite-DG/statistical.py` 的结构一致。

- Pie 使用 `category/value`、`arc` 和 `theta/color`，保留行顺序。顶层 `title` 是整张图表的标题。可选的 `theta.title` 表示实际指标名称及单位，例如「营业收入（万元）」；切换模式时保留该名称。百分比 GT 存储比例值，例如 `18%` 存为 `0.18`，通常使用 `theta.format: ".4~p"`。绝对数值保留原值并省略 `theta.format`。扇区排序字段、变换和环形样式留在 Compact GT 之外，表格直接使用 GT 的科学数值。
- 导入优先使用有效百分比格式，包括 `.0%`、`.12~%` 和 `.N~p`，缺少格式时兼容 DG 的 `usermeta.semantic.options.value_mode`。历史默认 `Share (%)` 和 `Value` 作为占位名称省略。只有标题或数值范围的旧文件按原值导入。核实数据确为比例后，可选择「确认导入值是 0–1 比例」；如果源值本身是 0–100 百分数，可切换到百分比模式。比例确认后导出仍保留原来的比例值和行序。
- `theta.format` 是两个平台的 Compact GT 字段。Vega-Lite 6.5.0 编译器可读取它，严格 Schema 会拒绝此字段。Studio 的渲染副本把格式放到 `tooltip.format`，保留原数据和扇区角度。角度测量继续使用百分比模式。
- 箱线图保持 `rule → bar → tick → point`。主 `data.values` 使用 `category/lower/q1/median/q3/upper`，`point.data.values` 使用独立的 `category/value` 离群点表。无离群点时 `point.data.values` 为 `[]`。`table_export` 将两张表分别导出为 Markdown 和 CSV，沿用 GT 原值与字段顺序。
- 纵向使用 `y/y2`，横向使用 `x/x2`。仅 `rule` 的主数值通道记录原图已有的轴标题和单位，以及所需的数值轴格式。`bar`、`tick`、`point` 的主数值通道只声明 `field` 和 `type: "quantitative"`，`x2/y2` 只声明 `field`。
- 原图数值刻度带 `%` 时使用 `rule` 层的 `axis.format`，新标注默认 `.4~p`，高精度刻度使用 `.N~p`。仅轴标题含 `(%)` 时，数值按普通刻度原样导出，省略 `axis.format`。历史 `.0%` 和 `.12~%` 可正常导入，重复的同一格式在导出时合并至 `rule`，冲突格式在导入时提示复核。格式迁移保留已有比例值和表格行序。
- 根据本任务的人工标注要求，不沿用生成器对 1.5×IQR 围栏的限制，不推断、排序、重算或舍入人工数据。人工录入及 GT 导入使用浏览器原生 JSON 数字，不额外做精度截断。箱线图从像素自动换算的结果（五数统计量、异常值、拖动、微调、校准重算）统一应用 Precision V2，保留完整原始像素坐标；导出和恢复沿用当前数据。若正四分位距在舍入后变为零，质量检查会提示复核。
- 预览单独设置箱体宽度和中位线颜色，并按百分比数据的范围显示刻度。原图无数值轴标题时，预览隐藏 Vega-Lite 自动拼接的字段名。预览设置只应用于渲染副本。
- GT 导入兼容旧版预计算箱线图的继承轴映射、`flatten/as + isValid` 形式，导出统一使用独立的离群点表。带额外顶层排序变换的旧 Pie GT 会明确拒绝，不做隐式有损迁移。

## 自动验证

`npm test` 包含 `tests/semantic.test.cjs`，对照原有图表的固定基准，并验证 Pie 的两种数值模式、横纵箱线图的轴声明、历史重复或冲突格式、独立离群点表及高精度值。校准测试覆盖正负数和对数轴，核对原始像素与参数的精度。

`npm run test:browser`：Chromium 实际浏览器验证，使用文件输入和 UI 操作，诊断接口仅用于读取结果。可设置 STUDIO_STAT_QA_OUTPUT 保存当次测试的截图、工程和结果。覆盖范围包括：

1. 五个代表样例的 GT 导入/下载、原图恢复、标题/单位保留、语义重绘、工程恢复及核对状态。
2. Pie 数据编辑、类别顺序、删除/撤销、百分比不满 100 的提示、切换绝对值模式及保存恢复。
3. 两个方向分别只校准一个数值轴，顺序点击五数统计量；各项独立选中和键盘微调，中位数拖动、重测；校准修改仅更新有像素依据的值。
4. 异常值连续取点、单项重测、手动增删、删除后的像素索引对应；全部删除后空数组的导出及再导入。
5. 统计量次序错误只提示、不修复；放大和投影辅助、缩放不改变原始坐标；完整像素、校准和数据的工程恢复及 IndexedDB 草稿刷新恢复。
6. 多图片队列和原散点图示例的校准取点流程。
7. 横纵箱线图在一个类别内、跨类别的近邻或完全重合点连续新增、默认字段推进及重复异常值；通过字段列表选中重合的统计量或异常值后单独拖动、微调；取点模式方向键不修改已有数据。
8. 原有柱图、折线和散点的 Alt 近邻取点、字段选中与拖动，以及柱图误差端点编辑。横纵堆叠的共享边界由 tests/stacks.mjs 独立覆盖。
9. Pie/Box 混合命名工作区、v2 备份恢复、切换图像、全屏/Escape，以及批量 ZIP 中的精确 GT、单位和跳过报告。
10. 从图表大类和子类下拉框直接切换到饼图、纵向箱线图和横向箱线图。核对两种方向的共享数值轴、百分比刻度、只在标题中带单位的普通刻度和无标题预览。

浏览器测试未捕获页面脚本异常。Vega 对所有异常值为空的四层 GT 可能输出空 extent 提示；数值轴由其他三层推断，预览及导出正常。测试不将此渲染器提示视为科学数据错误。

## 人工核验材料

打开 [`examples/statistical/index.html`](../examples/statistical/index.html) 查看：

| 样例 | 内容 |
| --- | --- |
| pie-percent | 百分比及高精度原始数值 |
| pie-absolute | `Revenue (万元)` 绝对值，未转百分比 |
| pie-donut | 同一 Pie 类型的环形预览 |
| box-vertical-outliers | `Duration (ms)` 纵向箱线图及异常值 |
| box-horizontal-empty | `Duration (ms)` 横向箱线图，无异常值 |

每个样例提供原图、GT、工程及平台截图。两个 `.measured.*` 补充样例由自动化操作真实执行取点、拖动、编辑和保存后生成，可打开工程继续检查像素标记。它们有意包含微调后的中位数和手动异常值，因此与原始合成图不完全相同；用于验证编辑证据和数据保存。样例工程中的核对勾选由自动测试操作，用于验证状态恢复，不表示已经经过人工验收。

样例、截图和随附的 JSON 测试报告记录的是 PR 提交时的结果。

## 新增与编辑交互修复

箱线图在「取点」模式下直接测量当前项，可连续标注近邻或重合的统计量。在「选择 / 拖动」模式中，从测量项或表格选中字段，然后拖动或用方向键微调。重合位置优先匹配已选字段。柱图、折线和散点仍可在取点模式中拖动标记，按住 Alt 点击可新增邻近的点。
