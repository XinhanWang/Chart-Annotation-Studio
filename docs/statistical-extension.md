# Pie / Box Plot 本地开发与验证

实现已迁移到最新 main 的 `studio.js` 与 `studio.template.html`，通过 `node build.mjs` 同步离线 `index.html`。没有新增运行时依赖或独立标注页面。统计图复用上游稳定类别对象、独立放大镜、校准、编辑、撤销、项目管理与批量 ZIP。工程沿用上游版本 2，并兼容版本 1 历史工程。

对照了同级 `Vega-Lite-DG/statistical.py`、已有生成样例，以及 `Vega-Lite-DG-pie-boxplot-pr/statistical.py` 和统计图测试。采用后者的最小 Compact 结构：

- Pie：`category/value`、`arc`、`theta/color`。保留数据行顺序，无 `order`、`row_number` 或 transform。环形样式只用于预览和工程，与 DG 的语义 GT 一致。
- Box：`category/lower/q1/median/q3/upper/outliers`，`rule + bar + tick + point` 四层；异常值使用 `flatten: ["outliers"]`。横向 x/x2，纵向 y/y2，轴标题附于数值映射。无异常值也保留四层和空数组。
- 根据本任务的人工标注要求，不沿用生成器对 1.5×IQR 围栏的限制，不推断、排序、重算或舍入人工数据。人工录入及 GT 导入使用浏览器原生 JSON 数字，不额外做精度截断。箱线图从像素自动换算的结果（五数统计量、异常值、拖动、微调、校准重算）统一四舍五入至两位小数，保留完整原始像素坐标；导出和恢复时不再对整表统一舍入。
- 预览单独设置箱体宽度和中位线颜色，避免默认样式遮住中位数；这些样式不进入 GT。
- GT 导入支持上述最小结构及旧版预计算箱线图的继承轴映射、`flatten/as + isValid` 形式。带额外顶层排序变换的旧 Pie GT 会明确拒绝，不做隐式有损迁移。

`npm test`：9 项语义测试通过。其中原有九种图表、柱图误差区间、导入后再导出，按最新版 main 的固定基准逐项比较，包含当前默认工程与历史工程/GT 规范化；保留上游 `errorbar`、C/X/S 身份及字段顺序；另验证两种 Pie 数值模式、两种箱线图方向、空异常值、精度、单位、校准换算、顺序错误及不应用 IQR 规则；新增自动测量两位小数测试，覆盖正负数和对数轴，同时确认原始像素及校准参数不被舍入。

`npm run test:browser`：Chromium 实际浏览器验证，使用文件输入和 UI 操作，诊断接口仅用于读取结果。结果见 [`browser-results.json`](../examples/statistical/browser-results.json)。覆盖：

1. 五个代表样例的 GT 导入/下载、原图恢复、标题/单位保留、语义重绘、工程恢复及核对状态。
2. Pie 数据编辑、类别顺序、删除/撤销、百分比不满 100 的提示、切换绝对值模式及保存恢复。
3. 两个方向分别只校准一个数值轴，顺序点击五数统计量；各项独立选中和键盘微调，中位数拖动、重测；校准修改仅更新有像素依据的值。
4. 异常值连续取点、单项重测、手动增删、删除后的像素索引对应；全部删除后空数组的导出及再导入。
5. 统计量次序错误只提示、不修复；放大和投影辅助、缩放不改变原始坐标；完整像素、校准和数据的工程恢复及 IndexedDB 草稿刷新恢复。
6. 多图片队列和原散点图示例的校准取点流程。
7. 横纵箱线图在一个类别内、跨类别的近邻或完全重合点连续新增、默认字段推进及重复异常值；通过字段列表选中重合的统计量或异常值后单独拖动、微调；取点模式方向键不修改已有数据。
8. 原有全部九类图表实际执行近邻/重合点新增、字段选中与拖动，覆盖堆叠起止点以及柱图误差端点编辑；语义 GT 与最新 main 基准由单元测试逐项比较。
9. Pie/Box 混合命名工作区、v2 备份恢复、切换图像、全屏/Escape，以及批量 ZIP 中的精确 GT、单位和跳过报告。

浏览器测试未捕获页面脚本异常。Vega 对所有异常值为空的四层 GT 可能输出空 extent 提示；数值轴由其他三层推断，预览及导出正常。测试不将此渲染器提示视为科学数据错误。

## 新增与编辑交互修复

原命中检测同时用于「取点」和「选择 / 拖动」，导致连续近邻标注被拦截为编辑已有点。现在仅编辑模式执行命中检测、拖动及键盘微调；取点模式直接处理当前目标，保留原有字段、类别和系列推进机制。编辑命中时优先使用命中范围内的已选字段，因此可先从现有字段列表或表格选中重合点，再独立修改。复用现有工具状态，没有新增模式或 UI。
