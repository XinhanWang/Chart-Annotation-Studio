# 气泡图标注与 Compact GT

在「散点图」中选择「单系列气泡图」或「多系列气泡图」。使用双连续轴校准圆心坐标，可设定记录数并在表格指定各行系列。默认按记录推进，最后一条取完后可继续添加。相同圆心的气泡各自保留。

## 大小与取点

| 录入方式 | 操作 | GT 大小字段 |
|---|---|---|
| 手动输入 | 取圆心，在表格填原图给出的大小。可选测整圆以显示轮廓。 | `size` |
| 大小校准 | 输入两个参考气泡的已知大小，分别测量两个参考圆。用它们建立 `size = a × r² + b`，表格手填值优先。 | `size` |
| 相对大小 | 在原图点击绘图区两个对角，再测量各气泡。所有系列共用绘图区。 | `size_relative` |

「圆心＋边缘」以两点距离为半径。「三点定圆」使用三个分散的可见圆周点，可测部分遮挡的圆。共线、过短圆弧或异常尺寸会要求复核。参考数值应随面积递增，参考半径过近会提示重新选择；参考范围外的外推值会提示复核。原图大小带百分号时，勾选大小百分比并录入原图显示的百分点，如把 25% 填为 25。原图有指标名称或单位时可填写。

相对值为 `Math.PI * r ** 2 / (W * H)`，其中 `r`、`W`、`H` 均为原图像素。即使边缘被裁切，公式使用完整圆面积。缩放图片不会改变原图坐标。添加或删除气泡不会改变其他气泡的分母。

圆心可在「选择 / 拖动」下调整，半径可通过「重测当前记录」更新。原图叠加已测轮廓。取点、X/Y 校准、大小校准各有独立撤销和重做。完全遮挡或无法可靠拟合时可标记 `needs_review`，工程保留待复核记录，处理前会阻止 GT 导出。全遮挡位置不会生成推测数据。

## GT 与预览

- 使用 `{"type":"point"}`。每行写 `x`、`y` 和一种大小字段，多系列用 `series` 及 `color.sort: null`，重名系列沿用既有系列身份规则。
- `encoding.size` 使用 quantitative。相对模式写 `{"field":"size_relative","type":"quantitative","legend":null}`。真实大小的指标及单位写入 `encoding.size.title`，百分比沿用以比例存储并通过图例格式显示的约定。
- 自动测量沿用 Precision V2。近零相对面积保留有效数字，手填真实大小保留原值。Markdown 和 CSV 逐条保留大小及系列，坐标重合的记录也分别导出。
- 渲染时使用填充圆形，相对大小根据预览实际绘图区计算面积。圆心像素、半径、绘图区边界和参考校准仅随工程保存。GT 导入可恢复数据和大小字段，`size` 导入后按已知数值处理。

可直接导入的示例见 [单系列手动输入](../examples/bubble/single-manual.gt.json)、[多系列大小校准](../examples/bubble/multi-calibrated.gt.json) 和 [多系列相对面积](../examples/bubble/multi-relative.gt.json)。
