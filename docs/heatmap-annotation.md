# 热力图标注

打开离线的 `index.html`，选择 **热力图**。离散 × 离散适用于矩阵、相关或混淆矩阵、三角矩阵和规则时间矩阵。连续 × 连续支持等宽与不等宽分箱。混合模式可选 X 或 Y 为连续轴。

1. 在「热力图行列」设置行列数量。列从左到右，行从上到下。离散轴可以逐项编辑或批量粘贴原始标签，一行一个。重名位置各自保留数值和证据。用箭头或排序按钮调整位置，删除带记录的行列前会提示确认。连续轴也可直接填写真实起止坐标，单个区间始终写小值到大值。
2. 在矩阵中用方向键切换到相邻格。输入数值后按方向键或 Enter 保存，Enter 按行优先前进。支持粘贴制表符、逗号或空格分隔的数字矩阵。页面从当前选中格粘贴，未选中时从左上角开始，空间不足时扩展网格。数值 `0`、负数和手填小数按原精度保存。空白省略该格，`null`（也接受 `NA`、`N/A` 或短横线）表示显式缺测。三角矩阵可以把不存在的格标为「结构空格」，批量测量会跳过它们。
3. 用「定位两角」指定原图网格的外框。所有模式都在已知边界之间自动等分，定位后即可在原图选格。不等宽的格子用「点取共享边界」修正。连续轴填写网格两端的真实值，或用坐标轴校准另取两个已知刻度。自动区间的起止值共用网格边界，按校准轴的原图像素解析度量化。改动边界或校准值后会重算。手填区间保留输入精度，有数值轴校准时也能反推原图边界。若区间的起止值舍入后相同，请手填更高精度。增删位置会清除所在轴的像素边界，连续区间重排前会保存已换算的数值。
4. 在「色标校准」点取色带内部两端，并填写真实数值。需要时加中间点，数值在相邻校准点之间分段线性换算。支持水平、垂直和反向色带，以及单向、多色和发散渐变。可测选中格、点原图格子或批量测量空格。自动取色在每格内部按 7 × 7 网格多点采样，取占多数的颜色，尽量避开格线、文字和异常像素。原图上的采样标记对应实际用于估值的像素。低置信度估值标在表格中，可选用建议值或直接手填。批量测量保留已有数值、显式缺测和结构空格。
5. 在语义重绘里核对原始标签、数值、缺格和区间。校准、原图、采样像素和估值依据随工作区备份保存。勾选原图和数值来源的人工核对后，可单图导出或批量打包 GT。

## GT 约定

精简 GT 使用 `mark: {"type":"rect"}`。每条观测都带 `x_id`、`y_id`，按视觉顺序自动编号为 `X1`、`Y1` 等，表格以行优先顺序导出。离散轴编码到 ID，使用 `ordinal` 和 `sort: null`，原始标签仍保存在 `x` 或 `y`。连续轴保留 `x/x2` 或 `y/y2` 真实边界。色标由定量字段 `value` 表示，图题、轴标题和色标指标名称及单位按需保留。预览使用独立的显示标签和绘图设置。原始七组示例见 [example.json](../example.json)。

未记录的格子在 GT 中省略，显式缺测输出 `value: null`。要保留整行或整列的标签或区间，至少标记一格为显式缺测。结构空格、像素和色标参数只随工程保存。

## 限制

- 网格按水平和垂直方向定位，目前每轴最多 1000 个位置，合计最多 10000 格。倾斜网格需先校正原图。连续轴标定支持线性和对数。语义预览连续区间默认使用线性尺度。
- 色标估值按源图分辨率、色带取样和校准点自适应确定精度，默认最多四位有效数字。背景色与有效色带颜色相同、色带多处同色或文字覆盖面积过大时，需要人工判定。改动色标校准后，质量检查会提示复核已有估值。
- `npm test` 包含七组示例的浏览器导入、导出、SVG 渲染和模拟原图测量，覆盖撤销、工程恢复和 ZIP 导出。
