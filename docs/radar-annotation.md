# 雷达图与极坐标柱状图标注

「雷达图」大类提供单系列雷达图、多系列雷达图、单系列极坐标柱状图、多系列极坐标柱状图和极坐标堆叠柱状图。普通折线和填充雷达图用前两个子类。用扇形柱表示数据的图用后三个子类。圆形和多边形网格共用校准流程。

## 校准和取点

1. 将类别按原图顺时针顺序录入。类别和系列可通过数量控件或名称批量输入，可在原对象列表改名和调整顺序。Compact GT 用类别和系列名称标识记录，同一列表中的名称须唯一。
2. 直接定位圆心，或分别在两条非平行径向轴上各取两个点以求交点。圆心也可以在坐标输入框中调整。
3. 点击两个已知径向刻度，填写实际数值。若圆心明确为零，可勾选「圆心为零刻度」，只需再取一个刻度。多边形网格应取径向轴和网格的交点。量程下限与上限填写原图的完整量程，独立于校准所选的两个刻度。雷达图允许非零起点的线性量程，极坐标柱状图采用零基线。
4. 标定首类别方向可生成等角辅助轴，并高亮当前类别。取点按原图像素与圆心的实际距离计算径向值，允许偏离辅助轴和取重合点。缩放或滚动不会修改已保存的像素几何。
5. 单系列和多系列普通雷达图及极坐标柱状图按系列优先取点。取完一个系列的最后一个类别，会切换到下一系列的首个待测类别。堆叠柱图按类别优先，每个类别可独立调整系列的内外顺序。依次点击各段的外边界，第一段从零起算，后续段继承前段外边界。取点或拖动可更新共有边界。重排有测量记录的类别时保留已确认段值，并清除与旧顺序关联的外边界证据。
6. 表格支持人工输入和修正。手填值在重新校准时保留。径向自动测量使用 Precision V2。显式百分比轴以百分点录入和测量，GT 转为比例并保留百分比格式。在普通轴中直接键入 `18%` 会保存为 `0.18`，输入 `18` 会保存为 `18`。
7. 极坐标柱可确认当前系列缺失，或标记待复核。待复核及未填值需要在导出前处理。明确为零的柱段通过表格填入 `0`。分组柱在某类别缺少一个系列时保留对应的角度槽位。每个分组系列至少需要一个观测，完全缺失的系列应从配置移除。

## Compact GT

| 子类 | `usermeta.chartType` | `mark.type` | 科学字段 |
| --- | --- | --- | --- |
| 单系列雷达图 | `radar` | `line` | `category`, `value` |
| 多系列雷达图 | `radar` | `line` | `category`, `value`, `series` |
| 单系列极坐标柱状图 | `polar_bar` | `bar` | `category`, `value` |
| 多系列极坐标柱状图 | `polar_bar` | `bar` | `category`, `value`, `series` |
| 极坐标堆叠柱状图 | `polar_bar` | `bar` | `category`, `value`, `stack_order`, `series` |

`encoding.x` 用 nominal `category`，显式列出顺时针 `sort`。`encoding.y` 用 quantitative `value`，包含 `title: null` 与完整的 `scale.domain`。单系列默认省略 `series` 和 `encoding.color`，启用原图图例时保留两者。多系列始终保留系列映射。

堆叠柱额外声明 `encoding.y.stack: "zero"` 与 quantitative `encoding.order.field: "stack_order"`。每个类别的段序号独立，从内到外从 1 连续编号。`value` 是段自身的数值。首尾闭合由渲染器处理。数据表先按类别，再按系列或堆叠序号排序。

`usermeta.table_export.tables` 为 `[{ "id": "data", "path": "/data/values" }]`，用于现有的 Markdown、CSV 和批量导出。画布圆心、刻度、测量点、辅助轴和堆叠边界由工程保存。原生 Vega 在预览时创建临时几何，Compact GT 保持长表。

显式携带 `y.stack: "zero"` 和连续 `stack_order` 的旧 `radar` / `line` GT 与旧 `radar_stack` 工程可迁移为极坐标堆叠柱。合成平台历史 `radar` GT 如缺少极坐标柱或堆叠标识，按普通雷达图导入。稀疏分组通过类别内部已记录的系列次序确定角度槽位，仅在系列之间缺乏相对次序依据时使用长表的首次出现顺序。

首版适用共享线性径向量程、等角类别和连续零基线堆叠。各维度独立量程、对数轴、非等角、三维及非零柱基线属于后续支持范围。运行 `npm run test:radar` 可验证 GT、预览几何、实际取点和导出。
