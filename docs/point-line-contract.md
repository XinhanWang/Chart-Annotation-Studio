# 散点与折线 GT 合约

散点的点击、表格录入顺序不限。导出训练 GT 时按全图画面 X 从左到右，同 X 按 Y 从上到下排序，系列之间统一排序。反向轴仍按画面顺序。工程保留原记录顺序、对象身份和逐点像素证据。

## 折线标注

单系列和多系列折线都可使用双连续轴，或将其中一轴设为 Nominal。X 离散时只校准 Y，类别从左到右填写。Y 离散时只校准 X，类别从上到下填写。要选另一离散方向，直接将对应轴设为 Nominal。各模式分别保留记录、类别位置、校准和原图像素，切回即可继续。工程备份包含各模式，GT 和批量导出使用当前模式。

批量输入类别时一行填写一个位置。用「定位当前类别刻度」记录原图位置。启用「固定类别位置」时，各系列共用同一个类别像素位置。直接取该类别的第一个点也能定位。连续轴取点、拖动及微调采用现有校准和 Precision V2，类别通过对象选择器修改。缺测时可跳到下一个目标或改用手动模式。

## 折线 Compact GT

普通折线统一导出 `mark.interpolate: "linear"`。历史 GT 缺省该属性时按 `linear` 导入。两轴沿用 `x/y` 科学字段。离散类型统一导出为 `nominal`，历史 `ordinal` X 可导入。年份、月份等离散标签按文本保存，同名不同位置按需使用 `x_id` 或 `y_id`。普通类别轴使用 `sort: null` 并按原图位置保存数据。科学标题与单位照原图保留，百分比格式只用于连续轴的百分比刻度。对数轴保留原始数值与 `scale.type: "log"`，逆向连续轴以 `scale.reverse: true` 表达。

Vega-Lite 根据类型推断混合轴折线的连接方向。普通折线沿离散轴位置连接，Y 离散时沿上到下的顺序。出现类别回退或同一位置的多个点时，每个系列独立使用 `path_order`，类别轴的 `sort` 同时显式声明显示顺序。双连续轴沿用原有规则，向画面左侧回退时输出 `path_order`，仅同 X 时通过 `mark.order: false` 保留连接次序。

`path_order` 只记录连接次序。缺失观测直接省略，剩余记录按各自系列的路径连接。像素、类别锚点和来源留在工程。`table_export` 直接从最终 GT 生成 Markdown 和 CSV。

## 平滑曲线

平滑曲线的标记为 `{"type":"line","interpolate":"monotone"}`。无标题的坐标轴省略 `title`，历史 GT 中的 `title: null` 可导入。支持双数值轴，也支持一条类别轴或时间轴搭配另一条数值轴。类别轴和时间轴均可放在 X 或 Y。双连续轴按路径取点，补已有路径中的观测时使用「插入采样点」。选中记录后可通过画布或表格修改数值，也可删除记录。连续轴观测值的自动测量沿用 Precision V2，手填观测值保留原有精度。

离散轴分两个阶段：

1. **固定点标注**：校准连续轴，输入类别名称，按画面顺序定位各类别刻度。每个系列在每个类别可标一个固定点，标完自动前进。原图缺少观测时用「跳过当前目标」。处理完固定点后，可以直接导出。
2. **自由采样**：固定点均标注或跳过后，点击「自由采样」。选择系列，在曲线上按任意顺序点击端点、峰谷和曲率变化的位置。系列保持选中，点击无需指定类别或录入位置。表格区分两类点，支持修改和删除。可随时切回固定点标注。

位置 ID 表示沿离散轴的连续相对坐标。取第一个类别为原点，以第一段有效类别间距为单位。等距固定点为 0、1、2……，非等距固定点保留实际相对间距。各系列共用同一组类别位置，自由采样根据相邻刻度的原始坐标线性映射。例如，A 到 B 的四分之一处为 0.25，B 到 C 的中点为 1.5。固定点在 `x` 或 `y` 保留原始类别名称，自由采样点在该字段保存为 `null`。

位置计算保留原始精度。GT 中的位置 ID 使用 number，默认四舍五入至最多两位小数，例如 0.253847 保存为 0.25，0.876532 保存为 0.88。同一系列中只有舍入后重合或顺序颠倒的位置需要增加保存精度，且尽量维持已有 ID。若类别位置需要细化，所有系列使用同一个细化后的 ID。删除样本不会重新分配其他样本 ID。同系列在原图上实际重合的采样位置需要人工复核。不同系列可以有相同位置。导出先按系列分组，再按各系列的位置升序排列。

等距固定点在类别名称唯一且分组后仍能保留轴顺序时使用 `nominal` 与 `sort: null`。当有自由采样、重复类别、非等间距或缺测导致分组后的类别顺序无法从数据行恢复时，使用 quantitative 的 `x_id` 或 `y_id`。历史平滑曲线的文字类别 ID 可导入，随后按位置导出为数值。普通折线的重复类别 ID 规则继续适用。完全没有观测的类别只写入相应轴的 `usermeta.x_labels` 或 `usermeta.y_labels`，结构为 `[{ "position": 1.5, "label": "未取点类别" }]`。在 nominal 模式下，标签位置使用从 0 开始的整数序位。

预览根据观测行和可选轴标签映射生成 `axis.values` 与 `axis.labelExpr`。离散 Y 沿画面纵向插值，在原生 Vega 预览中明确插值方向。Compact GT、Markdown 和 CSV 只包含实际采样点，预览产生的中间曲线和轴映射留在渲染层。表格导出保留原类别名和采样位置。

双连续轴的采样位置重合或回走会提示复核，显式断点和无法平滑的尖角可选中记录后标记待复核。遇到这类路径应核对原图、拆分为独立曲线，或采用符合原图的普通折线。闭合、回环、阶梯、混合线型以及自动描线属于本版支持范围之外。可单独导入的样例见 [examples/smooth-curves](../examples/smooth-curves)。

### 时间轴

在单系列或多系列平滑曲线的 X 或 Y 轴选择「时间」，另一轴使用「连续数值」。在原图取两个时间刻度并输入它们的文字，再校准数值轴。之后选择系列并自由取点。多系列共享时间校准，观测各自保存。

- 时间刻度支持年份、年月、年月日、不含年份的月份或月日，以及时分或时分秒。例如 `2024年`、`2024年1月`、`2024-02-29`、`1月`、`一月`、`Jan`、`Jan 15`、`13:20`、`1:20 PM`。时间轴上的两端刻度应同属含年日期、不含年日期或时刻。有年份的日期可跨年，只有月日或时刻的标签使用同一参考年或参考日内的顺序，跨界需填写原图上可确定的日期。
- 取点时按两个刻度间真实的日历或时刻差线性插值。年份和月份刻度分别以年初和月初作为插值起点；取点精度根据跨度选择。若同一系列内有不同采样点在当前精度下重合，会提高保存精度，必要时写出包含时间的日期字符串。确实重合的同系列观测需复核。不同系列可以有相同时间。
- GT 保持 `mark.type: "line"`、`mark.interpolate: "monotone"`，时间轴绑定原字段 `x` 或 `y`，类型为 `temporal`。数据先按系列分组，再按实际时间升序。常用格式为 `YYYY`、`YYYY-MM`、`YYYY-MM-DD`、`MM`、`MM-DD`、`HH:mm`、`HH:mm:ss`。细化时可使用 `YYYY-MM-DDTHH:mm:ssZ`、`MM-DDTHH:mm:ss` 或毫秒。缺年和纯时刻使用的内部参考年、参考日期不进入 GT。
- 预览解析时间字符串并设置轴显示格式；GT 和逐观测 Markdown、CSV 保留规范化字符串。时间轴不写位置 ID、`timeUnit`、解析配置或内部时间戳。工程保存校准与像素证据。
- 示例见 [横向完整日期](../examples/smooth-curves/single-x-temporal.json)、[纵向无年份日期](../examples/smooth-curves/multi-y-temporal.json) 和 [横向时刻](../examples/smooth-curves/single-x-clock.json)。

合成器 v1.4：所有图型取消逐点独立随机取整，数值保留采样原值。数值刻度使用一套确定数值同时生成位置和文字。冻结的上游采样函数仅作来源与回归证据，生产运行时显式应用新的数值策略，历史同 seed 图像不保证相同。

布局保留全部标签，不通过隐藏标签避免碰撞；横排单行长词也计入所需间距。轴标题不设置统一的大 maxExtent。缺少 Canvas 时按项目字体的 hmtx 字形 advance 测宽，字偶距与复杂文字整形仍是近似值。
