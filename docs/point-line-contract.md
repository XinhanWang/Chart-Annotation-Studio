# 散点与折线 GT 合约

散点的点击、表格录入顺序不限。导出训练 GT 时按全图画面 X 从左到右，同 X 按 Y 从上到下排序，系列之间统一排序。反向轴仍按画面顺序。工程保留原记录顺序、对象身份和逐点像素证据。

## 折线标注

单系列和多系列折线都可使用双连续轴，或将其中一轴设为 Nominal。X 离散时只校准 Y，类别从左到右填写。Y 离散时只校准 X，类别从上到下填写。要选另一离散方向，直接将对应轴设为 Nominal。各模式分别保留记录、类别位置、校准和原图像素，切回即可继续。工程备份包含各模式，GT 和批量导出使用当前模式。

批量输入类别时一行填写一个位置。用「定位当前类别刻度」记录原图位置。启用「固定类别位置」时，各系列共用同一个类别像素位置。直接取该类别的第一个点也能定位。连续轴取点、拖动及微调采用现有校准和 Precision V1，类别通过对象选择器修改。缺测时可跳到下一个目标或改用手动模式。

## 折线 Compact GT

两轴沿用 `x/y` 科学字段。离散类型统一导出为 `nominal`，历史 `ordinal` X 可导入。年份、月份等离散标签按文本保存，同名不同位置按需使用 `x_id` 或 `y_id`。普通类别轴使用 `sort: null` 并按原图位置保存数据。科学标题与单位照原图保留，百分比格式只用于连续轴的百分比刻度。对数轴保留原始数值与 `scale.type: "log"`，逆向连续轴以 `scale.reverse: true` 表达。

Vega-Lite 根据类型推断混合轴折线的连接方向。普通折线沿离散轴位置连接，Y 离散时沿上到下的顺序。出现类别回退或同一位置的多个点时，每个系列独立使用 `path_order`，类别轴的 `sort` 同时显式声明显示顺序。双连续轴沿用原有规则，向画面左侧回退时输出 `path_order`，仅同 X 时通过 `mark.order: false` 保留连接次序。

`path_order` 只记录连接次序。缺失观测直接省略，剩余记录按各自系列的路径连接。像素、类别锚点和来源留在工程。`table_export` 直接从最终 GT 生成 Markdown 和 CSV。

合成器 v1.4：所有图型取消逐点独立随机取整，数值保留采样原值。数值刻度使用一套确定数值同时生成位置和文字。冻结的上游采样函数仅作来源与回归证据，生产运行时显式应用新的数值策略，历史同 seed 图像不保证相同。

布局保留全部标签，不通过隐藏标签避免碰撞；横排单行长词也计入所需间距。轴标题不设置统一的大 maxExtent。缺少 Canvas 时按项目字体的 hmtx 字形 advance 测宽，字偶距与复杂文字整形仍是近似值。
